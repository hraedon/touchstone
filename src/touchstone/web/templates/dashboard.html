How to read this monitor
Read every figure here as an asking price. touchstone samples active listings, which is all the Browse API exposes. That pool skews high: stock priced correctly sells and leaves it; stock priced badly stays. A separate, clearly marked disappearance count records listings that stopped appearing — which may mean a sale, a seller ending the listing, or an expiry, and touchstone cannot tell those apart.
