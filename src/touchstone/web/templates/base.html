touchstone reports what sellers are asking for active listings, and how many listings stopped appearing. eBay exposes no completed-sale data to this application — Marketplace Insights is a gated Limited Release and findCompletedItems was retired — so nothing here is, or can be, a record of what anything actually changed hands for. Active asking prices skew high: inventory priced correctly leaves the pool, inventory priced badly stays in it.
